# 研究证据目录

本目录保存已完成的研究 JSON 证据，不是运行时配置，也不属于 Edge Scout 的正式 publication 输出。

- `results/`：当前可审阅的研究结果，按研究主题分组。保留文件名以便与预注册文档、历史 SHA-256 和命令输出对应。
- `archive/legacy/`：保留历史语义或当前代码无法完全重建的研究结果；不得把它们当作当前研究输出。

未来运行研究脚本时：

- 需要版本化、可审阅证据时，明确把 `--output` 指向此目录的对应主题文件；
- 新生成的一次性、探索性或 smoke 输出应写入被 Git 忽略的 `output/edge_scout/research/`；迁移时保留的既有 smoke 证据不代表后续默认输出位置；
- 正在运行的作业、缓存、日志、PID 和 checkpoint 应放在 `.runtime/`。

不要再将研究 JSON 直接写入项目根目录。
