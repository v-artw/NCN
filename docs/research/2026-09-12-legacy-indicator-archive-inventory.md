# 旧指标公式档案逐文件清点报告（../code · 2026-09-12）

## 1. 任务与方法

- 对象：`../code/` 67 个指标公式文件（53 txt + 14 docx，2024-10-19 收集，多为富途牛牛/通达信 TDX 语法及 TradingView Pine 转换稿、YouTube 群友分享代码）。
- 方法：docx 经 `textutil` 转文本（副本放 `/tmp/ncn_code_inventory/`，源目录零改动）；三个并行只读子代理对全部 67 个文件逐一读全文解析（每组约 8–13 分钟）；主代理另行用关键词扫描（RSV/CROSS/BACKSET/ZIG/DRAWICON）交叉核对分类结果。
- 判据框架：按当前阶段目标（选股精度 / 降误报）而非"收益提升"措辞评估；参照系为 MKF（RSV→SMA→SMA 随机指标家族、约 20/80 阈值状态机）。一份文件有价值，当且仅当它提供 MKF/scanner 输入中没有的正交信息维度，且规则收盘可算、不重绘、可精确移植。
- 本报告为只读清点：未运行任何回测，未改动任何项目代码，不含任何"该公式有效"的结论。

## 2. 总结论

1. 直接收益帮助：按原样采纳 = 无。67 个文件去重后约 62 个独立公式，其中 28 个不可用（同族冗余、纯显示、或含重绘/未来函数）、23 个仅供参考、16 个文件含可移植的候选规则形态。
2. 档案主体是经典振荡器的重包装：RSV→SMA 系（14 个文件）、KDJ/MACD/RSI 交叉状态机拼盘——与 MKF 同源同族，信息增量≈0。大量"高胜率/圣杯/逃顶/明日预测"命名为营销话术，无任何样本外证据。
3. 真正的价值集中在约 12 条规则形态、5 个正交维度：背离事件、波动率状态（挤压/爆发/棘轮通道）、衰竭计数、量价事件、乖离衰竭卖出。它们是 MKF 阈值状态机没有覆盖的"规则形状"，可作为预注册验证的假设素材。
4. 重绘红旗是本档案最大的陷阱：ZIG/BACKSET/CONST/REFX 共污染约 10 个文件（部分信号被污染、部分仅画线被污染）。含此类函数的公式若被 naive 移植进回测，会产出假高胜率，直接违反 AGENTS.md 的过拟合停止规则。
5. 若采用任何候选：一次只立项一条（建议从 1a 开始），走 H1/H2 同款纪律——单一假设、冻结门槛、生产 grid 全样本滚动次日验证、负结果记录。禁止对 12 条形态做批量挖掘。

## 5. 候选规则形态汇总（12 条 / 5 维度，均未验证）

所有候选已确认信号本体收盘可算、不重绘（个别需按注明重写）。参数与比较量取自原公式，验证时不得事后改动；任何"换参数再试"视为新假设。

### 维度一：背离事件类（价格-指标结构比较，MKF 无此形态）

**1a 交叉锚定单点背离**（来源 #50、#64、#9；统一模式，成本最低）
```
anchor(t) = t 之前最近一次 CROSS(fast, slow) 的 bar p
底背离 := CROSS(fast,slow)@t AND C[t]<C[p] AND Ind[t]>Ind[p]   # 价新低、指标抬高、当根收盘触发
四个实例:
  i.  fast/slow = MACD柱/EMA(MACD柱,5), Ind = MACD柱           (#50, 顶背离对称: 死叉锚, C[t]>C[p], 柱[t]<柱[p])
  ii. fast/slow = DIFF/DEA(12,26,9),       Ind = DIFF          (#64-B1)
  iii.测量对 = 慢速KDJ K1=SMA(SMA(RSV5,6,1),6,1), 触发对 = 快速KDJ(9,3,3) 金叉 (#64-B2, 慢测快触发)
  iv. fast/slow = RSI(6)/RSI(12),          Ind = RSI6          (#64-B3)
动量锚变体 (#9): turnUp[t]=M[t]>=M[t-1] AND M[t-1]<M[t-2]; M=EMA(B,2),
  B=A5+A8+A11+A14-4*A17, A_k=FORCAST(EMA(C,k),6);
  buyDiv = turnUp AND C[t]<C[t0] AND M[t]>M[t0], t0=上一 turnUp 根
```
共性：比较收盘价（非 LLV/HHV 窗）、单锚点、无未来函数。建议验证角色 = MKF 买入信号的确认过滤器。

**1b MACD 分段结构钝化背离·三态生命周期**（#42/43，档案中最独特形态，自带"作废"机制）
```
DIF=100*(EMA(C,SS)-EMA(C,LL)); DEA=EMA(DIF,MM); HIST=2*(DIF-DEA)   # 参数组 (12,26,9) 与 (3,15,6) 各跑一档
以死叉 CROSS(DEA,DIF) 分段: seg0 当前段, seg1 前段, seg2 前前段
CL_i = 段内最低收盘价; DL_i = 段内 DIF 谷值
norm(x, ref) = INTPART(x / 10^(INTPART(LOG|ref|) - 1))     # 数量级截断归一, DIFL=0 时跳过该段
钝化B := (CL0<CL1 AND norm(DIF)>norm(DL1) AND HIST<0 连续2根 AND norm(DIF)<=norm(DIF[1]))
        OR (CL0<CL2 AND CL2<CL1 的同构间接式); COUNT(B,2)=1 去重
结构形成BG := 前根钝化 AND norm(DIF) 转为抬升; FILTER(BG,10)      # 入场候选事件
消失 := 前根钝化 AND DL0<=DL1                                     # 背离作废, 10 根内否决
顶背离对称(金叉分段/HHV/HIST>0/FILTER 20)
```
移植警告：INTPART/LOG 截断量化必须逐位复现（不可换成连续比值），否则回退≠原式。

**1c RSI 枢轴背离（重写）**（#54）
```
枢轴高 p: RSI14[p]=HHV(RSI14[p-3..p+3]); 于 p+3 确认
顶背离 := C[p]>C[pPrev] AND RSI14[p]<RSI14[pPrev], 事件时点 = p+3   # 底背离对称
```
原式用 BACKSET 画回枢轴当根——回测取 p+3 为信号时点，否则即前视。

### 维度二：波动率/趋势 regime 类（ATR、带宽——MKF 完全缺失的信息维度）

**2a TTM Squeeze 挤压-释放**（#16 挤压部分；release 为清点补全，预注册须显式声明）
```
BBup=MA(C,20)+2*STD(C,20); BBlo=MA(C,20)-2*STD(C,20)
KCup=EMA(C,20)+EMA(TR,20); KClo=EMA(C,20)-EMA(TR,20)
squeezeON[t] = BBup<KCup AND BBlo>KClo        # 原式只比上轨, 标准 TTM 补双轨
release[t]   = squeezeON[t-1] AND NOT squeezeON[t]
```

**2b Waddah Attar Explosion 爆发/死区**（#67；档案中唯一"爆发力 vs 波动容量"比较）
```
ML=EMA(C,20)-EMA(C,40); T1=150*(ML[t]-ML[t-1]); E1=4*STDP(C,20); DZ=3.7*EMA_{α=0.01}(TR)
TU=max(T1,0); TD=max(-T1,0)
BUY := TU>=TU[1] AND TU>=E1 AND E1>=E1[1] AND E1>=DZ AND TU>=DZ AND NOT(前一根全同式)  # 首现边沿
SELL := CROSS(TD,E1) 首现
```

**2c Chandelier Exit 棘轮止损状态机**（#31）
