# MKF 极小资金实盘探针计划（target 4% vs 3%）

> **性质**：决策支持 / 研究复盘清单，**不是可执行 P&L，也不是买入建议**。
> 本计划不修改任何生产程序、selector、config、watchlist，也不经手真实资金。
> 真实交易决策由人在 2 万账户上自行执行；本清单只提供规则、门槛与对照。

## 一、边界与目标

- 本金：**20,000 元**（真实资金，用户自营）。
- 硬上限：**亏损 10% = 2,000 元**，权益到 18,000 即停，不补仓、不摊平。
- 探针目标（按时间成本优先，跳过 2 周纸面）：用极小资金验证 **MKF 信号在目标 4% 下能否扣费后为正 + 成交真实性**，而非追求"最大收益"。
- 失败即停：连续/累计触发失败门槛 → 到 2,000 就停，2,000 当作"真实成交认知"学费。

## 二、费用模型（三费）

- 佣金：万 2.5，每边 **5 元最低**。
- 印花税：0.05%，**仅卖**。
- 过户费：万 0.1，买卖双边。

**费率随仓位变化（仓位越大，5 元地板越被摊薄）：**

| 单笔仓位 | round-trip 费用 | 占仓位 |
|---|---|---|
| 2,000 | ~11 元 | ~0.55% |
| 2,500 | ~11.3 元 | ~0.45% |
| 5,000 | ~12.5 元 | ~0.25% |
| 10,000 | ~15 元 | ~0.15% |
| 20,000（全仓） | ~20 元 | ~0.10% |

**关键张力**：要过费需要大仓位（费率低），但大仓位让"一笔未命中"吃掉更多止损预算（见第三点）。

## 三、仓位与风控（把 10% 硬上限拆到每笔）

未命中的平均亏损约 **−8%**（各 target 相近，这是最大风险源）。让"一笔未命中 ≤ 止损预算的一小份"：

- 每笔仓位 **≈ 2,000–2,500 元**（≈ 2万 / 8 个并发槽）。
- 此时一笔 −8% 未命中 ≈ 亏 160–200 元 = 你 2,000 止损的 **8%–10%**（可承受）。
- 若放大到 5,000：一笔未命中 ≈ −400 = 止损的 20%；全仓 2 万：一笔 −1,600 = 止损的 80%（危险）。
- **同并发信号数 ≤ 3**；**每笔独立止损 / 触达即了结**。

## 四、入场 / 观察 / 成交真实性规则

- **入场**：父 MKF(v3 图表匹配)信号按指定 lag 确认后，取其后下一个"股票可交易日"**开盘价 `entry_open`** 试买。
- **观察窗口**：`T+1..T+20`；任意可卖交易日 `high ≥ entry_open×(1+target%)` 即命中、了结；否则观察到 **T+20 收盘**。
- **成交真实性校验**（探针真正的活）：
  - `entry_open` 当天**是否买得到**（涨停买不进？）；
  - 目标价**是否卖得掉**（排队/跌停卖不掉？）；
  - **T+1** 当天不可卖的约束；
  - 实际成交价 vs 理论 `entry_open`/目标价的**滑点**。
- 用**逐笔实盘记录**核对"理论命中"与"真实成交"偏差。

## 五、成功 / 失败门槛

- **成功**：`N` 笔（建议 ≥ 30，样本够稳）下来，**扣费后平均单笔收益 > 0**，且全程未触及 2,000 硬上限。
- **失败**：扣费后平均单笔收益 ≤ 0，**或**权益跌到 18,000，**或**连续 5 笔止损。
- 命中率的"高"≠成功：68% 命中仍可能期望为负（见第七点）。

## 六、target 4% vs 3% 对照（全样本 2021–2026，lag4，T+20）

| 维度 | **target 3%** | **target 4%** |
|---|---|---|
| 多数命中时间点 | **T+4**（~1 周） | T+7（~1.5 周） |
| T+20 最终命中率 | **74.4%**（最高档） | 68.4% |
| 扣费前 mean_return | **≈ 0%** | **+0.22%** |
| 未命中平均亏损 | ~ −8.7% | ~ −8.0% |
| 持有到过半命中 | 快 | 慢几天 |
| 单笔期望（2,500 仓，扣 ~0.45% 费） | 略负（≈ −10 元/笔） | 略负（≈ −5 元/笔） |
| 费用效率 | 低（收益太小付不起费） | 较高（收益高一档） |
| 适合场景 | 要"最快/最稳/低压力" | 要"相对多赚一点" |

**结论**：4% 在**每一个利润维度都胜过 3%**（扣费前均值更高、未命中尾巴更小、收益相对费更划算）；3% 唯一占优的是**命中更快**。追求利润 → 选 4%；追求快速周转/高胜率 → 选 3%。

## 七、诚实结论（费用挤压）

- **高命中率 ≠ 赚钱**：4% 有 68% 命中，但 32% 未命中平均亏 ~8%，把盈利吃光。
- 在 2 万、风险有效仓位（2,000–2,500）下，**0.22% 的扣费前优势被 ~0.45% 费用吃掉 → 大概率净负**。
- 要让正收益过费需要大仓位，但大仓位会让"一笔未命中"逼近 10% 止损 —— **结构上被夹住**。
- 因此探针**很可能只是确认"2 万体量下 MKF 扣费后不划算"**，这是**-required 的证据**（负结果也是证据），不是研究失败。

## 八、每笔记录字段

`日期 / 代码 / lag / entry_open / 成交价 / 目标价 / 真实成交价 / 命中orT+20收盘 / 持仓天数 / 毛利 / 费用 / 净利 / 与理论偏差 / 备注(涨停/排队/滑点)`

## 九、执行顺序

1. 先核对 2 万账户**费用口径与下单约束**（佣金最低额、印花税、T+1）。
2. 用**现有 MKF selector(lag0–lag5)产出候选**，按 target 4% 建立观察清单。
3. 极小资金（每笔 1–2 手）实盘探针，逐笔记录（第八章）。
4. 攒够 ≥30 笔 → 算扣费后期望；达成功门槛继续，达失败门槛停。
5. 结果回填 `HANDOFF.md`。
