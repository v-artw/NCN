# MKF 纸面/模拟探针 — 记录表模板（target 4%）

> 用法：每产生一个 MKF(lag0–lag5) 候选且你决定纸面试单，填一行。纯纸面/模拟，**不经手真实资金、不改生产**。

## 每笔字段

| 字段 | 说明 |
|---|---|
| 交易日 | 信号确认日 |
| 代码 | 股票 |
| lag | 0–5 |
| entry_open | 理论开盘入场价 |
| 真实成交价 | 纸面按 entry_open；真实下单填实际 |
| target(4%) | entry_open×1.04 |
| 结果 | 命中 / T+20收盘 / 未买入(涨停) / 未卖出(跌停顺延) |
| 成交价/日期 | 卖出价与日期 |
| 持仓天数 | T+? |
| 毛利 | (卖−买)/买 |
| 费用 | 佣金+印花税+过户费 |
| 净利 | 毛利−费用（占仓位%） |
| 与理论偏差 | 涨停/跌停/滑点说明 |
| 当日权益 | 纸面账户权益（用于画回撤） |

## 汇总（≥30 笔后）

- 笔数：__  胜率（成交命中/可成交）：__
- 扣费前均值：__  扣费后均值：__
- 最大回撤：__（是否触及 −10%/2000）
- 结论：过费(继续) / 不费(停)
