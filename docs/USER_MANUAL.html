02 · Daily Loop

日常推荐工作流

./main.sh daily --top 10
检查并按需更新本地日线

新闻 + K 线 AI 复核
冻结前瞻证据
审计成熟度并输出人工摘要

03 · Research Pipelines

扫描、SMC 与 MKF

Edge Scout

./main.sh scan ./main.sh scan --as-of 2026-08-21 ./main.sh scan-local

完整 run 发布到 output/edge_scout/<run-id>/，并通过 manifest 哈希保护。

单股分析

./main.sh single 600519 ./main.sh single-local sh.600519

六位数字会自动识别上交所/深交所前缀。默认 T 日为最新可见数据回退两个交易日。

SMC

./main.sh select-local --top 20 ./main.sh select-review --top 10

候选保存于 output/edge_scout/selections/；新闻复核保存于 news_reviews/。

MKF

./main.sh mkf-review --top 10 ./main.sh mkf-small --top 10

MKF 是独立候选源实验，不改变 SMC 候选或排序。候选源规则为：先识别上一交易日处于 MFK4 绿色背景块（momentum/inter/near <= 20），且红线 momentum 与蓝线 near 同时从 20 下方上穿到 20 以上、红蓝线仍低于 80 的上穿日；候选日取该上穿日当天、上穿日后的第 1 个或第 2 个股票可交易日。停牌日不消耗 lag，lag3 以后不入选。

重要：--top 只限制终端显示，不限制实际处理或保存数量。小样本 smoke 必须使用显式小候选 fixture。
04 · One Control Plane

统一 AI 模型配置

所有 AI 功能只读取 yaml/ai_providers.yaml。业务 YAML 不能覆盖模型、endpoint、密钥、timeout 或 response format。

字段当前值作用
providerlocal_finance全局切换所有 AI-backed 功能
base_urlhttp://ts.dorisw.kdns.fr:18090/v1Doris oMLX OpenAI-compatible endpoint
modelQwen3.8-27B-4bitMKF 与 SMC/news 共同模型
key priorityenv → key-file-env → key_file禁止 inline secret
thinkingdisabled保证结构化 JSON，不输出长推理

切换 provider

# yaml/ai_providers.yaml provider: deepseek

新增 provider 后将其设为 enabled: true，再修改顶层 provider。运行时不会静默 fallback。

连接验证

PYTHONPATH=src .venv/bin/python -B scripts/smoke_ai_provider.py \ --config yaml/ai_providers.yaml --models-only PYTHONPATH=src .venv/bin/python -B scripts/smoke_ai_provider.py \ --config yaml/ai_providers.yaml --chat

Doris 已验证：模型列表可用、tiny JSON chat 可用、隔离的 MKF 与 SMC/news 三候选 smoke 均 3/3 成功。

10 · Recovery

故障排查

数据字段缺失

missing_value: Record N field 'turn' must not be None

修复或重新下载 Parquet；不要为了通过扫描而放宽严格数据契约。

Doris AI 401

  • 先运行 models-only smoke。
  • 确认 endpoint 明确包含 /v1 且协议正确。
  • 确认 env key 或 Key/ts.key 与服务端一致。
  • 密钥权限使用 0600，绝不输出到日志或 Git。

Qwen 返回空 JSON / 长推理

确认 chat_template_kwargs.enable_thinking=false 只配置在 Doris backend。

AI partial / unavailable

查看 review run 的 summary.json：ai_error_counts、ai_client_status、ai_provider、ai_model。系统不会静默换 provider。
